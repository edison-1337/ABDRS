Barangay Document Request System / Architecture 01

Frontend architecture

The browser owns presentation and nothing else. Plain HTML pages, three CSS layers, and vanilla ES modules under public/ call the Express API and nothing more — no rule about a request status or an SMS ever exists in browser code, and no credential is ever served to the browser.

No build step

Pages are served as written. CSS is layered as base, components, then layouts, so a shared primitive changes once and every page inherits it.

One API client

public/js/lib/api-client.js is the only module that performs network calls. It attaches the session, normalizes the error envelope, and never handles a domain decision.

Nothing secret is served

public/ contains no credential and no server code. The TextBee key, the session secret, and every SQL statement stay behind the API boundary.

Evidence: public/css, public/js, src/routes, src/middleware, src/lib, README.md architecture section.
