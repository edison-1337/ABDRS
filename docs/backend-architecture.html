Barangay Document Request System / Architecture 02

Backend architecture

Express route handlers are the server boundary and own no rules. The request domain and the SMS domain live in src/lib and decide everything; Supabase PostgreSQL is the only system of record, and TextBee is reached exclusively by a background outbox worker so gateway throughput can never fail a citizen request.

Route boundary

Route handlers parse input, enforce auth, call the library, and return JSON. They never decide a legal transition, a severity, or a message body.

Outbox, not inline send

A status change and its sms_outbox row commit together. The worker drains the queue under a throttle, so a busy gateway or a 429 can never roll back a citizen's approval.

Gateway authenticity

Delivery receipts are HMAC-SHA256 verified over the exact raw body and de-duplicated on idempotencyKey before they may change a message status.
